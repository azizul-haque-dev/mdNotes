# Step 1.1 — Monorepo Root Setup

**লক্ষ্য:** pnpm workspace দিয়ে monorepo root তৈরি করা, যেখানে `mobile` আর `backend` দুটো আলাদা প্যাকেজ থাকবে কিন্তু shared tooling (TypeScript strict base, Prettier) কমন থাকবে।

## যা করতে হবে

```bash
mkdir arabic-learning-app && cd arabic-learning-app
mkdir mobile backend
corepack enable
```

## ফাইল তৈরি করুন

**`package.json`**

```json
{
  "name": "arabic-learning-app",
  "private": true,
  "version": "0.1.0",
  "engines": {
    "node": ">=20.0.0",
    "pnpm": ">=9.0.0"
  },
  "scripts": {
    "mobile": "pnpm --filter mobile start",
```

## Test করুন

```bash
pnpm -v          # pnpm ইনস্টল আছে কিনা দেখুন
cat pnpm-workspace.yaml   # ঠিকভাবে বসেছে কিনা
```

এখনো `pnpm install` চালানোর দরকার নেই — `mobile/` আর `backend/`-এ এখনো কোনো `package.json` নেই। পরের সাব-স্টেপে backend দিয়ে শুরু করব।
