# Step 2.3 — Mobile Auth: Supabase Client Setup (Secure Storage)

> এই ধাপে শুধু Supabase client + secure session storage বসবে। কোনো login UI এখনো না।

---

## 1. Dependencies install

```bash
npx expo install @supabase/supabase-js expo-secure-store aes-js react-native-get-random-values react-native-url-polyfill
```

- `expo-secure-store` → শুধু encryption key রাখার জন্য (session না)
- `aes-js` + `react-native-get-random-values` → session data encrypt করার জন্য
- `react-native-url-polyfill` → React Native-এ `URL` না থাকায় supabase-js-এর জন্য দরকার

---

## 2. `.env` (mobile)

```env
# .env
EXPO_PUBLIC_SUPABASE_URL=https://your-project-ref.supabase.co
EXPO_PUBLIC_SUPABASE_ANON_KEY=your-anon-key-here
EXPO_PUBLIC_API_BASE_URL=http://localhost:5000
```

⚠️ `EXPO_PUBLIC_` prefix মানে এই ভ্যালু app bundle-এ compile হয়ে যায় — এটা normal, কারণ `anon` key client-side-এ expose হওয়ার জন্যই বানানো (secret না)। `service_role` key মোবাইল কোডে **কখনোই** আসবে না, ওইটা শুধু backend-এ।

`app.config.ts`-এ (যদি typed env চাও) অথবা সরাসরি `process.env.EXPO_PUBLIC_*` দিয়ে access করবে।

## 3. Large Secure Store adapter

Supabase session object 2048 byte limit-এর চেয়ে বড় হতে পারে, তাই direct SecureStore ব্যবহার করলে crash করবে (নতুন SDK version-এ error থ্রো করে, আগে শুধু warning দিত)। তাই session **AsyncStorage-এ AES দিয়ে encrypted অবস্থায়** রাখব, আর শুধু ছোট encryption key-টা SecureStore-এ থাকবে।

```bash
npx expo install @react-native-async-storage/async-storage
```

```typescript
// src/lib/supabase/largeSecureStore.ts
import 'react-native-get-random-values';
import * as aesjs from 'aes-js';
import * as SecureStore from 'expo-secure-store';
import AsyncStorage from '@react-native-async-storage/async-storage';

class LargeSecureStore {
  private async getEncryptionKey(keyName: string): Promise<Uint8Array> {
    let encryptionKeyHex = await SecureStore.getItemAsync(keyName);

    if (!encryptionKeyHex) {
      const randomBytes = new Uint8Array(32);
      crypto.getRandomValues(randomBytes);
      encryptionKeyHex = aesjs.utils.hex.fromBytes(randomBytes);
      await SecureStore.setItemAsync(keyName, encryptionKeyHex);
    }

    return aesjs.utils.hex.toBytes(encryptionKeyHex);
  }

  async getItem(key: string): Promise<string | null> {
    const encrypted = await AsyncStorage.getItem(key);
    if (!encrypted) return null;

    const keyName = `${key}_encryption_key`;
    const encryptionKey = await this.getEncryptionKey(keyName);

    const [ivHex, cipherHex] = encrypted.split(':');
    if (!ivHex || !cipherHex) return null;

    const aesCtr = new aesjs.ModeOfOperation.ctr(
      encryptionKey,
      new aesjs.Counter(aesjs.utils.hex.toBytes(ivHex)),
    );
    const decryptedBytes = aesCtr.decrypt(aesjs.utils.hex.toBytes(cipherHex));

    return aesjs.utils.utf8.fromBytes(decryptedBytes);
  }

  async setItem(key: string, value: string): Promise<void> {
    const keyName = `${key}_encryption_key`;
    const encryptionKey = await this.getEncryptionKey(keyName);

    const ivBytes = new Uint8Array(16);
    crypto.getRandomValues(ivBytes);

    const aesCtr = new aesjs.ModeOfOperation.ctr(encryptionKey, new aesjs.Counter(ivBytes));
    const encryptedBytes = aesCtr.encrypt(aesjs.utils.utf8.toBytes(value));

    const ivHex = aesjs.utils.hex.fromBytes(ivBytes);
    const cipherHex = aesjs.utils.hex.fromBytes(encryptedBytes);

    await AsyncStorage.setItem(key, `${ivHex}:${cipherHex}`);
  }

  async removeItem(key: string): Promise<void> {
    await AsyncStorage.removeItem(key);
    await SecureStore.deleteItemAsync(`${key}_encryption_key`);
  }
}

export const largeSecureStore = new LargeSecureStore();
```

## 4. Supabase client

```typescript
// src/lib/supabase/client.ts
import 'react-native-url-polyfill/auto';
import { createClient } from '@supabase/supabase-js';
import { AppState } from 'react-native';
import { largeSecureStore } from './largeSecureStore';

const supabaseUrl = process.env.EXPO_PUBLIC_SUPABASE_URL;
const supabaseAnonKey = process.env.EXPO_PUBLIC_SUPABASE_ANON_KEY;

if (!supabaseUrl || !supabaseAnonKey) {
  throw new Error('Missing EXPO_PUBLIC_SUPABASE_URL or EXPO_PUBLIC_SUPABASE_ANON_KEY in .env');
}

export const supabase = createClient(supabaseUrl, supabaseAnonKey, {
  auth: {
    storage: largeSecureStore,
    autoRefreshToken: true,
    persistSession: true,
    detectSessionInUrl: false, // mobile-এ URL-based session detection দরকার নাই
  },
});

// App background-এ গেলে token auto-refresh বন্ধ, foreground-এ ফিরলে আবার চালু —
// এটা না করলে background-এ unnecessary refresh call হতে থাকবে, ব্যাটারি/data নষ্ট হবে
AppState.addEventListener('change', (state) => {
  if (state === 'active') {
    supabase.auth.startAutoRefresh();
  } else {
    supabase.auth.stopAutoRefresh();
  }
});
```

## 5. যাচাই করো এটা কাজ করছে কিনা

কোনো স্ক্রিনে temporarily test করতে পারো (permanent কোড না, শুধু sanity check):

```typescript
import { supabase } from '../src/lib/supabase/client';

useEffect(() => {
  supabase.auth.getSession().then(({ data, error }) => {
    console.log('Session:', data.session, 'Error:', error);
  });
}, []);
```

App চালু করলে কোনো error ছাড়া `Session: null` আসা উচিত (এখনো login করা হয়নি বলে)।

## এই অংশে যা হলো

- Supabase client production-safe secure storage সহ সেট হলো (2048 byte limit bypass, AES encryption)
- App foreground/background অনুযায়ী token auto-refresh optimize করা হলো
- এখনো কোনো UI নাই — পরের ধাপে (2.4) Zustand auth store দিয়ে app-wide session state manage করব

## পরের ধাপ (2.4)

Zustand auth store — `session`, `user`, `isLoading` state + `onAuthStateChange` listener, যাতে পুরো app জুড়ে যেকোনো screen থেকে auth state পড়া যায়।
