# Step 1.5 — Express App + Server (প্রথম রান!)

**লক্ষ্য:** সব middleware একসাথে wire করে `app.ts` বানানো, আর `server.ts`-এ সার্ভার বুট + graceful shutdown।

## ফাইল তৈরি করুন

**`backend/src/app.ts`**

```typescript
import compression from "compression";
import cookieParser from "cookie-parser";
import cors from "cors";
import express, { type Express } from "express";
import rateLimit from "express-rate-limit";
import helmet from "helmet";
import { pinoHttp } from "pino-http";

import { env } from "./config/env.js";
import { logger } from "./config/logger.js";
import { errorHandler } from "./middleware/errorHandler.js";
import { notFoundHandler } from "./middleware/notFound.js";
import { sendSuccess } from "./utils/ApiResponse.js";

export function createApp(): Express {
  const app = express();

  // Security & parsing
  app.use(helmet());
  app.use(
    cors({
      origin: env.CORS_ORIGIN.split(",").map((origin) => origin.trim()),
      credentials: true,
    }),
  );
  app.use(compression());
  app.use(express.json({ limit: "1mb" }));
  app.use(express.urlencoded({ extended: true, limit: "1mb" }));
  app.use(cookieParser());
  app.use(pinoHttp({ logger, autoLogging: env.NODE_ENV !== "test" }));

  // Rate limiting — applied to the whole API surface; tighten per-route later
  // (e.g. a stricter limiter on /auth) once that module exists.
  app.use(
    "/api",
    rateLimit({
      windowMs: env.RATE_LIMIT_WINDOW_MS,
      max: env.RATE_LIMIT_MAX,
      standardHeaders: true,
      legacyHeaders: false,
    }),
  );

  app.get("/health", (_req, res) => {
    sendSuccess(res, { status: "ok", uptime: process.uptime() });
  });

  // Feature routers are mounted here one module at a time, e.g.:
  //   app.use('/api/v1/categories', categoriesRouter);
  // See src/modules/README.md for the per-module structure convention.

  app.use(notFoundHandler);
  app.use(errorHandler);

  return app;
}
```

**`backend/src/server.ts`**

```typescript
import { createApp } from "./app.js";
import { connectDatabase, disconnectDatabase } from "./config/db.js";
import { env } from "./config/env.js";
import { logger } from "./config/logger.js";

async function main() {
  await connectDatabase();

  const app = createApp();
  const server = app.listen(env.PORT, () => {
    logger.info(`API listening on port ${env.PORT} (${env.NODE_ENV})`);
  });

  const shutdown = (signal: string): void => {
    logger.info(`${signal} received — shutting down gracefully`);

    server.close(() => {
      disconnectDatabase()
        .catch((error: unknown) =>
          logger.error({ err: error }, "Error during DB disconnect"),
        )
        .finally(() => process.exit(0));
    });

    // Force-exit if connections don't close in time.
    setTimeout(() => process.exit(1), 10_000).unref();
  };

  process.on("SIGTERM", () => shutdown("SIGTERM"));
  process.on("SIGINT", () => shutdown("SIGINT"));
}

main().catch((error: unknown) => {
  logger.error({ err: error }, "Fatal error during startup");
  process.exit(1);
});
```

**`backend/src/modules/README.md`**

```markdown
# Feature modules

Each feature (categories, lessons, words, sentences, progress, bookmarks,
downloads, ...) gets its own folder here, fully self-contained:
```

src/modules/categories/
categories.routes.ts # express.Router — wires HTTP verbs to controller fns
categories.controller.ts # parses req, calls service, calls sendSuccess/next(err)
categories.service.ts # business logic, orchestrates repository calls
categories.repository.ts # the only place that talks to Mongoose models
categories.model.ts # Mongoose schema + model
categories.validation.ts # zod schemas for params/query/body
categories.types.ts # module-local TypeScript types (if needed)

```

Rules of thumb:

- Controllers never import Mongoose directly — only repositories do. This
  keeps the data layer swappable and makes services unit-testable without a
  database.
- Validation happens in the router via a small `validate(schema)` middleware,
  before the request ever reaches the controller.
- Cross-module reads (e.g. "progress" needing "lessons" data) go through the
  other module's service, never its repository — respect the module boundary.
- A module is mounted in `src/app.ts` with one line:
  `app.use('/api/v1/categories', categoriesRouter)`.

This mirrors the mobile app's `src/features/*` convention, so the same
mental model applies on both sides of the stack.

```

## আর্কিটেকচার নোট

- Feature module (categories, lessons, ...) পরে `app.ts`-এ এক লাইনে মাউন্ট হবে: `app.use('/api/v1/categories', categoriesRouter)`। কনভেনশন `src/modules/README.md`-এ লেখা আছে।
- Rate limiting শুধু `/api` পাথে — `/health` limit-এর বাইরে, যাতে monitoring/uptime check ব্লক না হয়।
- Graceful shutdown: `SIGTERM`/`SIGINT` পেলে আগে HTTP সার্ভার বন্ধ, তারপর MongoDB disconnect, ১০ সেকেন্ডের মধ্যে না হলে force-exit।

## `.env` বসান

```bash
cd backend
cp .env.example .env
```

`.env`-এ আসল মান বসান:

- `MONGODB_URI` — MongoDB Atlas connection string
- `SUPABASE_URL`, `SUPABASE_JWKS_URI` — আপনার Supabase প্রজেক্টের
- `SUPABASE_SERVICE_ROLE_KEY` — Supabase Dashboard → Project Settings → API
